## How to publish on GitHub Pages
1. Create a GitHub account with username `sumerajabeen` (or use your own username).
2. Create a new **public** repository named exactly `sumerajabeen.github.io`
   (replace with `<your-username>.github.io`).
3. Click **Add file → Upload files** and drag in everything inside this folder
   (`index.html`, `README.md`, `.nojekyll`, and the `animation` folder). Commit.
4. Go to **Settings → Pages**, set Source = *Deploy from a branch*, Branch = `main`, folder `/ (root)`. Save.
5. Wait 1–2 minutes, then open:
   https://sumerajabeen.github.io/animation/web/LinearSearchNew.html
